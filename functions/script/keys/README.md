# Keys

Esta carpeta contiene placeholders de credenciales para ambientes Firebase.

## Archivos

- `firebase-sa.json`
- `firebase-sa-staging.json`
- `firebase-sa-prod.json`

## Importante

- No subir llaves reales al repositorio.
- Reemplazar el contenido placeholder por el JSON real del service account correspondiente.
- Validar que `project_id` coincida con el ambiente.

## Ambientes sugeridos

- `firebase-sa.json`: local o base
- `firebase-sa-staging.json`: staging
- `firebase-sa-prod.json`: producción
